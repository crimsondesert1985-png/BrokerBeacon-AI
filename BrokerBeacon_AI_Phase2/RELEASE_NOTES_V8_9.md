# BrokerBeacon AI v8.9 — Live Official Guide Search

## Added
- Natural-language and keyword search from the Loan Guidelines workspace.
- Program filter for Fannie Mae, Freddie Mac, FHA, VA, USDA, or all programs.
- Live retrieval restricted to official agency domains.
- Official page titles, detected guide section numbers, concise source excerpts, and direct source links.
- One-click example searches for common mortgage scenarios.
- 30-minute in-memory result caching to reduce repeated external requests.
- Parallel program searches so all-guide queries return faster.
- Direct official-guide fallback links when an agency site or search provider cannot be reached.

## Important limitations
- Search requires outbound internet access from the Render web service.
- Some agency policies are published in PDFs or applications that do not expose searchable page text; those results may provide a source link without an excerpt.
- Results are a research aid and do not replace the current controlling guide, AUS findings, Union Home Mortgage overlays, or underwriting approval.
