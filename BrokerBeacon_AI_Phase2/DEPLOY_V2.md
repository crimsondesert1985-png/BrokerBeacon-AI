# Deploy BrokerBeacon AI 2.0

1. In GitHub Desktop, choose **Repository → Show in Explorer**.
2. Open the repository's `BrokerBeacon_AI_Phase2` folder.
3. Delete the old contents of that folder, but do not delete the parent repository folder or `.git` directory.
4. Copy every file from this package's `BrokerBeacon_AI_Phase2` folder into the repository's `BrokerBeacon_AI_Phase2` folder.
5. Return to GitHub Desktop.
6. Commit with: `Upgrade to BrokerBeacon AI 2.0 clean build`.
7. Click **Push origin**.
8. Render should redeploy automatically. If not, use **Manual Deploy → Deploy latest commit**.
9. Verify `/health`, then `/demo`.
