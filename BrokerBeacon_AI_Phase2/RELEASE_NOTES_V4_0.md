# BrokerBeacon AI 4.0 — AI Copilot

## Implemented
- Database-grounded morning briefing.
- Ask BrokerBeacon command box with ranked answers.
- Queries for location, state, overdue follow-ups, high scores, government fit, and niche-product fit.
- Explainable priority score combining opportunity score, pipeline stage, staleness, and recorded follow-up urgency.
- Copilot results link directly to the existing broker intelligence profile.
- Pre-call profile summary renamed and positioned as the Copilot pre-call brief.

## Important boundary
The Copilot does not claim email opens, current licensing changes, production volume, or external facts unless those values exist in the application's database. No paid AI API or API key is required for this release.
